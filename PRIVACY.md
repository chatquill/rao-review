# Privacy policy

Last updated: October 8, 2026

rao-review is a set of written instructions for Claude. It has no code, no servers, no MCP connectors and no analytics.

## What it handles

Inside your own Claude session, the skill reads the diff or pull request you point it at, files in your repository that it needs to verify a finding, and your answers to its questions. It reads pull requests with the `gh` CLI you have already signed in to.

## What it stores or sends

Nothing. The plugin does not store, log or send any data anywhere. It does not post to GitHub unless you ask it to. Its author never receives your code or anything else from your session.

Your conversations are handled by Claude itself, under Anthropic's own privacy policy.

Questions about this policy: open an issue at https://github.com/chatquill/rao-review/issues
